Care Navigation Support @VERSION@ for Mac
For @CHIP_LABEL@ Macs with macOS 13 Ventura or later

Install
1. Open the ZIP in Finder. Keep the extracted folder together.
2. Quit any running copy. Double-click Install Care Navigation Support.command.
3. When Finder opens, double-click Care Navigation Support. The app is in
   the Applications folder inside your home folder.

The installer uses built-in Mac tools and adds a local test signature.
A launch check on an actual Mac is still needed. If macOS or your
organization blocks the download, ask IT to review the package. A
Developer ID signature and Apple notarization are needed for routine
distribution through Gatekeeper.

Try the app using an invented case
- Ask for transportation in North York. Select a card, record a result
  and save a score. Check the rating beside its Known services contact.
- Save or keep the chat. In Manage memory, delete one practice note from
  its preview. Quit and reopen to check that the other record remains.
- Try Speak and allow the microphone when macOS asks. Review the words
  before sending. Replies appear in text.
- Use Connect ChatGPT to test an eligible account. Reopen the app to
  check that the connection and Keychain prompt behave as expected.
