# Southlake Care Navigation Support 2.4.0 — clearer navigation

- Ask assistant now sits in the upper-right of the Known services heading, clear of the service rows.
- Manage memory is directly beneath Known services in the sidebar. Connection & backup remains at the bottom.
- Ask assistant beneath each View details button still opens the floating chat with that service selected. Minimize, Escape, Open Workspace, drafts, automatic memory and the memory manager retain their existing behavior.

## Install or update

Close the current app, then run **Southlake-Care-Navigation-Support-Setup-2.4.0.exe** and complete installation. Existing accounts, documents and memory use the same Windows data location. Updates require the new installer; no automatic updater is included.

## Validation and scope

81 automated checks and the native Windows layout, floating-chat, document and memory checks are recorded in Verification.json. Header/button placement is checked at normal and compact window sizes, including the button staying clear of service rows.

The installer remains an unsigned prototype. Live recipient ChatGPT eligibility/inference, microphone capture on that computer, publisher signing and Southlake deployment approval remain separate checks. No private records or credentials are included in the download.
