# Southlake Care Navigation Support 2.3.0 — full-page services and floating assistant

- Known services fills the page, including the existing horizontal service rows, contact information, category filter and search. The chat beneath the directory has been removed.
- A floating Ask assistant button on the right opens a side panel without shrinking or moving the directory.
- Ask assistant stays underneath View details on each row. It opens the panel with that provider selected so feedback stays on the correct service card.

## Install or update

Close the current app, then run **Southlake-Care-Navigation-Support-Setup-2.3.0.exe** and complete installation. Existing accounts, documents and memory use the same Windows data location. No automatic updater is included.
