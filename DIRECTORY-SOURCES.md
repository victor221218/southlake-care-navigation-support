# Known services — research sources

Version 2.1 preloads the 27 public service pathways researched for the earlier app. Each card shows its source review date. Contact/source checks were refreshed on 18 November 2026 for the entries marked below; other retained entries show their earlier 13 November date. These are saved summaries, not a live capacity feed. Confirm program eligibility, exact service boundaries, costs, contacts and capacity with the provider. No actual patient history, user feedback, success rates or satisfaction scores are preloaded.

Named contacts appear only when explicitly listed by the public provider. Otherwise use the listed phone or program email. A public contact can change; use the source page to confirm before referring.
