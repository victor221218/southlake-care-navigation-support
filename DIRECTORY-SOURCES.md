# Public directory sources — reviewed 13 November 2026

The desktop app includes 27 starting service pathways. These are saved summaries, not a synchronized service-availability feed. No real provider success rates or satisfaction scores are seeded. Program fit, exact service boundaries and current capacity must be confirmed with the provider.

Each linked page was consulted for the program summary. A dead North York Seniors Centre PDF link was replaced with its current transportation page. Registration/membership wording and fare details on its pages should be confirmed with intake. For Ontario Health atHome the current public referral page supplies the provincial contact number. Circle of Care and CHATS are separated by the iRIDE north/south-of-Steeles access route.
